# Muhammad Hamza Portfolio

A polished React portfolio built with Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

Edit `src/main.jsx` to update:

- Name and headline
- Project cards
- Skills
- Email and GitHub links

Edit `src/styles.css` to adjust colors, spacing, and layout.
